# kunitaka-photo-2

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A collection of 3D photogrammetry models of intersections and other locations in Fukui Prefecture, Japan.

You can view a composite model on Sketchfab:

## 3D Models

This repository contains the following models:

| Filename | Description | Format |
|---|---|---|
| `武生高校前交差点.glb` | Intersection in front of Takefu High School | `.glb` |
| `武生高校前交差点2.glb` | A second scan of the Takefu High School intersection | `.glb` |
| `武生高校前三叉路.glb` | 3-way intersection (T-junction) at Takefu High School | `.glb` |
| `国高公民館前交差点.glb` | Intersection in front of the Kunitaka Community Center | `.glb` |
| `八幡魚八.glb` | Street view including the "Uohachi" restaurant at the Yahata intersection | `.glb` |
| `瓜生町危険箇所写真.usdz` | A potentially hazardous spot in Uryu Town | `.usdz` |
| `瓜生町危険箇所写真-edit.glb` | An edited version of the Uryu Town model | `.glb` |
| `レンタカー.glb` | A rental car in a parking area | `.glb` |

## Technical Details

- **Format**: The models are provided in glTF (`.glb`) and USDZ (`.usdz`) formats.
- **Creation**: The original scans were captured and processed using [Scaniverse](https://scaniverse.com).
- **Editing**: The `瓜生町危険箇所写真-edit.glb` model was further processed using Blender.

## Usage

No installation is required. The models can be loaded and viewed in any application that supports the glTF 2.0 or USDZ formats.

- **Web:** [Three.js](https://threejs.org/), [Babylon.js](https://babylonjs.com/), [model-viewer](https://modelviewer.dev/)
- **Desktop:** Blender, Windows 3D Viewer, macOS
