# kunitaka-photo-2

福井県内の交差点やその他の場所の3Dフォトグラメトリモデルのコレクションです。

## ライブデモ

Sketchfabで複合モデルをご覧いただけます：

**[➡️ Sketchfabで見る](https://sketchfab.com/3d-models/kunitaka-photo-2-c023034ce67a4e12af7d1da21b16d270)**

## 3Dモデル

このリポジトリには以下のモデルが含まれています：

| ファイル名 | 説明 | フォーマット |
|---|---|---|
| `武生高校前交差点.glb` | 武生高校前の交差点 | `.glb` |
| `武生高校前交差点2.glb` | 武生高校前交差点の2回目のスキャン | `.glb` |
| `武生高校前三叉路.glb` | 武生高校前の三叉路（T字路） | `.glb` |
| `国高公民館前交差点.glb` | 国高公民館前の交差点 | `.glb` |
| `八幡魚八.glb` | 八幡交差点にある飲食店「魚八」周辺のストリートビュー | `.glb` |
| `瓜生町危険箇所写真.usdz` | 瓜生町の危険箇所 | `.usdz` |
| `瓜生町危険箇所写真-edit.glb` | 瓜生町モデルの編集版 | `.glb` |
| `レンタカー.glb` | 駐車場のレンタカー | `.glb` |

## 技術的詳細

- **フォーマット**: モデルはglTF（`.glb`）およびUSDZ（`.usdz`）形式で提供されています。
- **作成**: オリジナルのスキャンデータは、[Scaniverse](https://scaniverse.com)を使用して撮影・処理されました。
- **編集**: `瓜生町危険箇所写真-edit.glb`モデルは、Blenderを使用してさらに処理されています。

## 使用方法

インストールは不要です。モデルは、glTF 2.0またはUSDZ形式をサポートする任意のアプリケーションで読み込んで表示できます。

- **Web:** [Three.js](https://threejs.org/)、[Babylon.js](https://babylonjs.com/)、[model-viewer](https://modelviewer.dev/)
- **デスクトップ:** Blender、Windows 3D Viewer、macOS
